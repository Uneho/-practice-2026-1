О проекте

Концепция, архитектура и технологии

Концепция

Основная идея — модульное построение интерфейса мессенджера. Каждая панель является независимым визуальным блоком со своей цветовой схемой. Блоки могут настраиваться независимо друг от друга.

Alt разрабатывается как российская альтернатива Discord для IT-команд, онлайн-школ и игровых сообществ — аудитории, которая лишилась привычной среды постоянного общения после блокировки зарубежных сервисов.

💡 Вдохновением послужил Discord с его чётким делением на функциональные панели: серверы, каналы и область сообщений.

Технологии

  • Matrix — федеративный протокол для текстовых и голосовых каналов, основа self-hosted развёртывания
  • WebRTC — голосовая связь с низкой задержкой
  • ГОСТ-шифрование, КриптоПро — защита данных по требованиям РФ
  • REST API — открытый интерфейс для ботов и интеграций
  • 2FA — двухфакторная аутентификация учётных записей

Лента сообщений

Три блока мессенджера

  • Список серверов — узкая боковая панель с иконками сообществ и собственным фоном.
  • Лента каналов — перечень каналов с индикаторами активности и счётчиками.
  • Область чатов — основное рабочее пространство с лентой сообщений.

Кастомизация блоков

Каждый блок поддерживает полную настройку через панель Стиль: цвет фона, акцента и текста, семейство шрифта и его размер. Расположение и размер блоков фиксированы — изменяется только их оформление. Все настройки сохраняются в localStorage отдельно для каждой страницы.
